Política de Privacidade

Última atualização: 30 de maio de 2026

1. Informações que coletamos

Este aplicativo acessa dados públicos do Instagram, como nome de usuário e comentários feitos em publicações, exclusivamente para fins de automação de respostas. Nenhuma senha ou dado sensível é coletado.

2. Como usamos as informações

As informações coletadas são usadas apenas para enviar respostas automáticas a comentários e mensagens diretas no Instagram, conforme solicitado pelo próprio usuário ao interagir com as publicações.

3. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos dados de usuários a terceiros. As informações são utilizadas exclusivamente para a funcionalidade descrita acima.

4. Armazenamento de dados

Este aplicativo não armazena dados pessoais em banco de dados próprio. As interações são processadas em tempo real e não são retidas após o processamento.

5. Direitos do usuário

O usuário pode, a qualquer momento, revogar o acesso do aplicativo à sua conta do Instagram por meio das configurações de privacidade da plataforma.
